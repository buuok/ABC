声音统一（Windows 版）使用说明
================================

【打开】
1. 先把整个压缩包“全部解压”（右键 → 全部解压缩），不要在压缩包里直接双击。
2. 进入 VoiceUnify 文件夹，双击 VoiceUnify.exe。
3. 第一次打开时，Windows 可能弹出蓝色的“Windows 已保护你的电脑”：
   点“更多信息”→“仍要运行”。（因为这个程序没有购买数字签名证书，不是病毒。）
   如果杀毒软件拦截，请选择“允许”。
4. 会出现一个黑色窗口（程序本体），同时浏览器自动打开操作界面。
   如果浏览器没自动打开，就复制黑窗口里显示的地址（例如 http://127.0.0.1:8765）到浏览器里打开。
5. 用完后关闭黑色窗口即可退出。

【使用】（界面上按 1→2→3→4 的顺序走就行）
1. 添加文件：把音频或视频拖进网页，可以一次拖很多个，也可以点“选择整个文件夹”。
2. 选主音色：默认以第一个文件为准，也可以在列表里点“设为主音色”。
   经常用同一个声音时，点“存为常用主音色”，以后只添加新片段、直接选“★ 名字”即可。
   同一句话生成了好几条时，点“比一比哪段最像主音色”，每段会打分，挑分数最高的；60 分以下建议重新生成。
3. 选方案：不确定就用“AI 配音统一（推荐）”，音量默认“跟主音色一样响”。高级设置一般不用改。
   某一段听着还是不像（比如更粗、更闷）：在文件列表那一行点“🎚 调音色”，拖动滑块
   （音调、嗓音粗细、厚度、清晰度、明亮），点“▶ 试听调整后”马上听效果，满意后再点“开始处理”。
   不知道从哪调起就点“按主音色给个建议值”；几段问题一样时点“这组设置用到所有文件”。
4. 点“开始处理”，进度条会显示处理到第几个文件。处理完自动保存，点“打开输出文件夹”就能看到。
   视频保持原画面，只替换为处理后的声音。

【注意】
- 处理结果自动保存在程序旁边的“输出”文件夹里，每次处理一个子文件夹（按日期时间命名）。
- 全程离线，文件不会上传到任何地方（“上传”只是传给本机上的这个小程序）。
- 不要删除或移动 bin 文件夹里的 ffmpeg.exe，处理视频要用它。
- 文件夹路径里最好不要有特殊符号；放在桌面或 D 盘根目录都可以。
- 只支持 64 位 Windows 10 / 11。

【第三方组件】
- Node.js 运行时（MIT 许可）：https://nodejs.org
- FFmpeg（GPL/LGPL 许可，源代码见 https://ffmpeg.org）
