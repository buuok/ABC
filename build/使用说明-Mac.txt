声音统一（Mac 版）使用说明
============================

【选对版本】
- 苹果芯片（M1/M2/M3/M4）：下载 VoiceUnify-Mac-AppleSilicon.zip
- Intel 芯片：下载 VoiceUnify-Mac-Intel.zip
  （查看方法：左上角苹果菜单 → 关于本机 → “芯片”或“处理器”）

【打开】
1. 双击 zip 解压，得到 VoiceUnify 文件夹。
2. 第一次：在“声音统一.command”上【右键 → 打开】，弹窗里再点“打开”。
   如果提示“无法打开，因为无法验证开发者”且没有“打开”按钮（macOS 15 以后常见）：
   打开“系统设置 → 隐私与安全性”，往下拉，找到关于“声音统一.command”的提示，点“仍要打开”，再输入密码确认。
3. 会出现一个终端窗口（程序本体），同时浏览器自动打开操作界面。
   如果浏览器没自动打开，就把终端里显示的地址（例如 http://127.0.0.1:8765）复制到浏览器打开。
4. 以后直接双击“声音统一.command”即可。
5. 用完后关闭终端窗口即可退出（提示“终止进程”时点“终止”）。

【使用】（界面上按 1→2→3→4 的顺序走就行）
1. 添加文件：把音频或视频拖进网页，可以一次拖很多个，也可以点“选择整个文件夹”。
2. 选主音色：默认以第一个文件为准，也可以在列表里点“设为主音色”。
   经常用同一个声音时，点“存为常用主音色”，以后只添加新片段、直接选“★ 名字”即可。
   同一句话生成了好几条时，点“比一比哪段最像主音色”，每段会打分，挑分数最高的；60 分以下建议重新生成。
3. 选方案：不确定就用“AI 配音统一（推荐）”，音量默认“跟主音色一样响”。高级设置一般不用改。
   某一段听着还是不像（比如更粗、更闷）：在文件列表那一行点“🎚 调音色”，拖动滑块
   （音调、嗓音粗细、厚度、清晰度、明亮），点“▶ 试听调整后”马上听效果，满意后再点“开始处理”。
   不知道从哪调起就点“按主音色给个建议值”；几段问题一样时点“这组设置用到所有文件”。
4. 点“开始处理”，进度条会显示处理到第几个文件。处理完自动保存，点“打开输出文件夹”就能看到。
   视频保持原画面，只替换为处理后的声音。

【注意】
- 处理结果自动保存在 VoiceUnify 文件夹里的“输出”文件夹，每次处理一个子文件夹（按日期时间命名）。
- 全程离线，文件不会上传到任何地方。
- 不要删除 runtime 和 bin 文件夹。

【第三方组件】
- Node.js 运行时（MIT 许可）：https://nodejs.org
- FFmpeg（GPL/LGPL 许可，源代码见 https://ffmpeg.org）
